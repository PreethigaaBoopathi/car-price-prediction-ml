# 🚗 Car Price Prediction using Machine Learning

## 📌 Overview
This project predicts car prices based on manufacturing year using Machine Learning regression models.

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## 🤖 Models Used
- Linear Regression
- Polynomial Regression
- Ridge Regression

## 📊 Features
- Data preprocessing
- Train-test split
- Model comparison using R² score
- Future price prediction
- Data visualization

## 📂 Dataset
The dataset contains:
- Car Name
- Year
- Price

## 🚀 Output
The model predicts future car prices based on manufacturing year trends.
